# Portal escolar em Angular

Evolução do cadastro de excursões para Angular 16: tela de login, barra de navegação, páginas com rotas e formulário de cadastro.

Projeto de estudo de 2023 (Angular / TypeScript), mantido aqui como registro da minha evolução.

## Como rodar

```bash
npm install
npx ng serve   # http://localhost:4200
```

## O que pratiquei

- Migração de um projeto de JavaScript puro para Angular
- Componentes de layout e rotas
- Formulários no Angular
